# 🚤 ボートレース2連単予想ゲーム（修正版）

第5R・6R・7Rの2連単を参加者がスマホで予想し、実際の払戻金がそのままポイントになるイベント用アプリです。
**サーバー（Node.js）は不要**です。主催者のブラウザが「親機」になり、スマホとP2P通信で同期します。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `管理画面を開く.bat` | 主催者用。Edgeで admin.html を開く |
| `admin.html` / `admin.js` | 主催者画面（QR表示・締切・結果確定・ランキング・CSV保存） |
| `index.html` / `app.js` | 参加者画面（スマホ用） |

CSVにはPASS番号の列が入ります（Excelで先頭の0が消えないよう `="0123"` 形式で出力）。
| `app.css` / `peerjs.min.js` / `qrcode-generator.js` | 共通部品 |

旧版の `server.js` `engine.js` `start.bat` `*.vbs` `state.json` は不要なので削除しました。

## 事前準備（1回だけ）：参加者用ページを公開する

スマホが開く `index.html` は、インターネット上のURLに置く必要があります。
（主催者PCの `localhost` や `file://` のアドレスは、スマホからは開けません）

1. このフォルダ一式を、静的サイトの公開サービス（Netlify Drop、GitHub Pages など）にアップロードする
2. 公開された `index.html` のURLを控える（例: `https://xxxx.netlify.app/index.html`）
3. 主催者画面の「⚙️ 参加者URLの設定」にそのURLを貼って「更新」を押す（この設定はこのブラウザに保存されます）

QRコードの中身は「そのURL ＋ `?host=ルームキー`」になります。

## 当日の流れ

1. **`管理画面を開く.bat`** をダブルクリック（Chrome/Edge）
2. 画面上部の **「📁 dataフォルダを選択」** を押し、CSVの保存先フォルダを選ぶ（毎回の確認：「連動中」と緑色で出ること）
3. 参加者がQRコードを読み取る（スマホはモバイル回線でもWi-Fiでも可。会場のインターネット接続が必要）
4. 進行：「第○レース」を選ぶ → 「🟢 投票受付を開始する」 → 発売締切で「🛑 締切にする」 → 結果と2連単の払戻金を入力して「結果を確定」
5. 第6R・第7Rも同様。最後にランキングを投影

> レースタブを切り替えると、投票受付は**自動で停止**します（意図せず次のレースが受付開始にならないため）。切り替え後に「投票受付を開始する」を押してください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 管理画面を閉じた／再読み込みした | 同じ方法でもう一度開けば、データ・ルームキーとも引き継がれ、参加者は自動で再接続されます。画面上部が「前回の接続の解放待ち」と出たら数十秒待つ |
| フォルダ状態が「許可が必要です」になった | 「🔁 フォルダ連携を再開」を押して許可する（ブラウザを開き直すたびに必要になることがあります） |
| 参加者がつながらない | ① 管理画面の「P2P受付中」が緑か ② 参加者URLが正しいか ③ 会場Wi-Fiの「端末間通信の遮断」がONになっていないか（スマホをモバイル回線にして試す） |
| QRが出ない | 赤い警告に従い、参加者URLを設定する |
| ルームキーが使用中と出た | 「ルームキーを再発行」を押す（QRが変わるので参加者は読み直し） |

## 注意

- **管理画面は、いつも同じ方法（同じURL／同じブラウザ）で開いてください。** データはそのブラウザの中に保存されるため、開き方を変えると前のデータが見えません（CSVには残っています）。
- 管理PCのスリープは必ずオフに。画面スリープ防止は自動で試みますが、非対応のPCもあります。
- 参加者は「ニックネーム＋PASS番号（数字4桁）」の組み合わせで区別します。名前の全角/半角・大文字小文字の違いは同じ名前として扱います。
  - 同じ名前でもPASS番号が違えば、別の人として登録できます。2人目以降が同名で登録しようとすると、入力ミスでないか確認が出ます。
  - 主催者画面のランキングでは、同名の人に（1）（2）と付けて区別します（PASS番号は画面に出しません）。
  - **PASS番号を間違えて入れると別人扱い**になり、同じレースにもう一度投票できてしまいます。受付で「PASS番号は忘れないように」と案内してください。
  - 景品の受け渡しなどで本人確認が必要なときは、`ranking.csv` のPASS番号列と本人に言ってもらった番号を照合できます。
  - 4桁の数字なので、強い本人認証ではありません（なりすましを「しにくくする」程度）。
- 「データ初期化」は、実行前にCSVを自動でバックアップします（フォルダ連携中はそのフォルダ内、未連携ならダウンロード）。

## 旧版からの主な修正点

1. QRが長いURLで生成できない問題を修正（QRライブラリを差し替え）。localhost/ファイル表示のままだとスマホで開けない旨を警告表示
2. ルームキーを保存して再利用（管理画面の再読み込みでも参加者が切れない）。参加者側も切断後に自動再接続
3. 参加者の履歴・ポイントは主催者のデータを正として表示（初期化後も「投票済み」が残る問題、名前を変えると他人の履歴が出る問題を解消）
4. 他人の予想は結果確定まで参加者に送信しない
5. CSVの引用符エスケープ、Excelの数式として解釈される名前の無害化、確定日時が毎回書き換わる問題を修正
6. フォルダ連携を記憶し、再開ボタン・保存失敗の表示を追加
7. 管理画面の再読み込み後にレース表示と内部状態がずれる問題を修正
8. 初期化前の自動バックアップ、画面スリープ防止を追加
